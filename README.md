# VideoCleaning

Лёгкий видеоредактор для удаления наложений (в основном текста: хардсабов,
надписей, логотипов) с 2D-анимации — «ретушь в Фотошопе, только для видео».

Чистый Rust: единственный внешний инструмент — системный `ffmpeg`/`ffprobe`
как отдельный процесс. Опциональный AI-режим использует [ProPainter]
(ICCV 2023) через маленький python-сайдкар.

[ProPainter]: https://github.com/sczhou/ProPainter

## Возможности

- **Плеер**: плавный просмотр с фоновой подгрузкой кадров (LRU-кэш),
  слайдер-таймлайн, горячие клавиши (Space — играть, ←/→ — ±1 кадр,
  Shift+←/→ — ±25 кадров, Ctrl+Z/Y — история).
- **Маски**: прямоугольник, кисть, полигон; диапазон кадров у каждой маски
  (маркеры на таймлайне); undo/redo; список масок справа.
- **Превью результата** на текущем кадре, четыре стратегии:
  - *фон* — восстановление из кадров-доноров слева/справа (основной режим
    для 2D-анимации с закадровым текстом);
  - *нейросеть* — мини‑U‑Net (burn, чистый Rust CPU), обучение на месте;
  - *LaMa* — ONNX-модель (лучшее качество на крупных областях);
  - *Telea* — классический инпейнтинг (фолбэк).
- **🔍 Поиск текста**: автоопределение текстовых областей на кадре —
  локальный контраст → компоненты → группировка в строки; найденные области
  добавляются как готовые маски (один undo), дальше — ручная правка.
- **Экспорт**: кодирование через `ffmpeg` (x264 CRF 14–28, аудио-дорожка
  копируется из оригинала), прогресс и отмена.
- **Видео-инпейнтинг ProPainter** (опционально): нейросетевое удаление
  текста/логотипов по всему клипу:
  - экспорт строится по **сегментам**: маски группируются в кластеры по
    времени, каждый кластер обрабатывается со своим кропом — кадры между
    кластерами проходят без обработки (не рендерится лишнее);
  - тучные кропы автоматически считаются в пониженном разрешении
    (long side ≤ 1024) — влезает в VRAM потребительского GPU;
  - на выходе полная длина ролика, кадры вне масок — без изменений,
    звук на всём протяжении;
  - живой прогресс: полоса, фаза (с номером сегмента), счётчик кадров,
    прошло/осталось.
- **Проект**: сохранение/загрузка `.vcproj` (JSON: источник + маски).

## Сборка и запуск

Нужен Rust 1.85+ (edition 2024) и `ffmpeg`/`ffprobe` в PATH
(или переменные `FFMPEG_PATH` / `FFPROBE_PATH`).

```sh
cargo build --release
cargo run --release -p vc-gui --bin videocleaning
# либо через скрипт с изоляцией памяти (Linux/systemd — см. ниже):
./scripts/run-gui.sh
```

Отладочная трассировка запуска: `VC_TRACE=1` (seek декодера, причины отбраковки
в детекторе текста).

### AI-режим (ProPainter, опционально)

Чекбокс «Видео-инпейнтинг ProPainter» в диалоге экспорта активен, когда
рядом с репозиторием есть:

1. **venv** — `tools/venv` с python 3.10+ и `torch` (CUDA), `opencv-python`,
   `imageio`, `imageio-ffmpeg`, `tqdm`, `numpy`:

   ```sh
   python3 -m venv tools/venv
   tools/venv/bin/pip install torch --index-url https://download.pytorch.org/whl/cu126
   tools/venv/bin/pip install opencv-python imageio imageio-ffmpeg tqdm numpy
   ```

2. **Код ProPainter** — `tools/propainter-repo` (клон
   [sczhou/ProPainter](https://github.com/sczhou/ProPainter)).

3. **Веса** — `tools/propainter-repo/weights/`: `ProPainter.pth`,
   `raft-things.pth`, `recurrent_flow_completion.pth` (выдаются в README
   ProPainter).

Пути переопределяются переменной окружения `VC_PROPAINTER_REPO`; по умолчанию
сайдкар ищет репозиторий ProPainter по пути `tools/propainter-repo` рядом с
проектом. Отладка сайдкара: `VC_PROPAINTER_KEEP_WORK=1` оставляет рабочую
директорию.

Во время AI-экспорта пишутся логи рядом с результатом:
`<имя>.export.log` — фазы/проценты/итог, `<имя>.vcvideo.log` — stderr
ProPainter (tqdm); полезны при разборе ошибок и OOM.

### Изоляция памяти (Linux/systemd)

`scripts/run-gui.sh` запускает GUI в отдельном systemd scope с лимитами
памяти (`MemoryHigh=6G`, `MemoryMax=10G`): systemd-oomd при пике убьёт
только приложение, а не родительский терминал/IDE. Внутри скрипт делает
`reset-failed`, чтобы упавший unit не блокировал перезапуск.

## Архитектура (workspace)

| Крейт       | Содержимое |
|-------------|-----------|
| `vc-core`   | `Frame` (RGBA8), маски (`Shape`: Rect/Polygon/Brush), растеризация, таймкод |
| `vc-codec`  | `CodecBackend` (ffprobe-метаданные, rawvideo-декод), `Player` (стример+LRU), `export` (ffmpeg-энкодер со скользящим окном доноров) |
| `vc-inpaint`| `telea` (FMM), `background` (доноры соседних кадров), `nn` (мини-U-Net на burn/Flex), `lama` (ONNX), `patchmatch`, `pipeline` (выбор стратегии) |
| `vc-detect` | детектор текста: контраст → компоненты → группировка строк (SWT) |
| `vc-gui`    | eframe/egui: viewport, инструменты, таймлайн, панели, экспорт, AI-экспорт (`export_ai.rs`) |

Python-сайдкар: `tools/propainter/inpaint_cli.py` — сегментированный
прогон ProPainter (кропы, маски, вставка результата, кодирование),
протокол прогресса по stdout (`PROGRESS extract/painter_run/paste/done`).

Этапы разработки и журнальные решения — в [`PLAN.md`](PLAN.md).
Инструкция для агентов (как работать с кодовой базой) —
в [`AGENT.md`](AGENT.md).
